# RFC

**全称**：Request For Comments

把设计或方案写成文档，拍板前拿出来讨论，实现前先对齐方向。和 [[zh/Glossary/ADR|ADR]] 的区别在于，RFC 是讨论中的提案，ADR 记的是已经拍板的方案。

![影响范围大的改动先用 RFC 记录提案并征求评审，此时设计仍可调整。](../Diagrams/rfc.proposal-review.svg)

用例：

> 这次改动影响范围大，先写份 RFC 让团队过一遍。
