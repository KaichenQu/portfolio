# CL

**全称**：Changelist

提交给别人审或准备合进仓库的独立代码改动。Google 和 Phabricator 体系里这么叫，对应 GitHub 的 [[zh/Glossary/PR|PR]]。「Send up a CL」就是把改动发出去请人审。

![分支改动通过 PR 提交评审，获得认可后再合入主线。](../Diagrams/pr.review-flow.svg)

用例：

> 拆成两个 CL 吧，先重构，再加功能，审起来省劲些。
