# PR

**全称**：Pull Request

GitHub 上发起审查和合并的方式，请人审查你的分支改动，再合进主线。GitLab 叫 [[zh/Glossary/MR|MR]]，Google 这套体系叫 [[zh/Glossary/CL|CL]]。

![分支改动通过 PR 提交评审，获得认可后再合入主线。](../Diagrams/pr.review-flow.svg)

用例：

> 这个 PR 太大，审查的人很难看完，再拆小些。
