# PR

**全称**：Pull Request

GitHub 上发起审查和合并的机制：请人审查你分支上的改动，审完合进主线。GitLab 里叫 [[zh/Glossary/MR|MR]]，Google 体系里叫 [[zh/Glossary/CL|CL]]。

![分支改动通过 PR 提交评审，获得认可后再合入主线。](../Diagrams/pr.review-flow.svg)

用例：

> 这个 PR 太大，审查的人很难看完，再拆小点。
