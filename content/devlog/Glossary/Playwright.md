# Playwright

**Full name**: Playwright (browser automation library)

A library and CLI that drives real Chromium, Firefox or WebKit browsers from code: open pages, click, type, read the DOM, capture screenshots and network traffic. It is used to write [[e2e]] tests and to script page checks against a dev server.

Example usage:
> Three parallel Playwright rounds ran against a local stack: 20 cards generated, 10 replaced, and lost create and submit responses recovered with the same ids.
