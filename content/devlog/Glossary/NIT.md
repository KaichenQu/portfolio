# NIT

**Full name**: Nitpick

A minor, non-blocking suggestion in review (naming, formatting, phrasing) — addressing it usually doesn't gate the merge. Plural is written NITS.

Example usage:
> NIT: the variable name `data` is too generic, but non-blocking, LGTM.
