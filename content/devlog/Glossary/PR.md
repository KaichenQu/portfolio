# PR

**Full name**: Pull Request

GitHub's way of requesting review and merge: ask someone to review your branch's changes and merge them into the mainline. GitLab calls it [[MR]]; the Google world calls it [[CL]].

Example usage:
> This PR is too big for the reviewer to get through — split it smaller.
