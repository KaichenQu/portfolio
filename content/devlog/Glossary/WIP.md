# WIP

**Full name**: Work In Progress

Marked on a [[PR]] title or commit to say: don't review, don't merge, still in progress.

![A pull request brings branch changes to code review before they are merged into the mainline.](../Diagrams/pr.review-flow.svg)

Example usage:
> WIP: opening this PR as a placeholder to run CI — don't merge.
