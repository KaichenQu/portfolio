# RFC

**Full name**: Request For Comments

Writes up a design or proposal as a document and puts it out for discussion before deciding. Used to align direction before implementation. Versus [[ADR]]: an RFC is the proposal under discussion; an ADR is the decision already made and recorded.

Example usage:
> This change has a big blast radius — write an RFC and get the team to review it first.
