# POC

**Full name**: Proof of Concept

Proves at minimum cost that an idea or technical approach works — usually a throwaway experiment, not held to production quality. Once it's proven, discard it; don't promote it straight into production code.

Example usage:
> Write a POC first to check whether this library can handle the concurrency, then design it properly.
