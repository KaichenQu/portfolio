# LGTM

**Full name**: Looks Good To Me

Signals approval in code review — no issues found. Common in approval comments on [[PR]]s / [[CL]]s.

![A pull request brings branch changes to code review before they are merged into the mainline.](../Diagrams/pr.review-flow.svg)

Example usage:
> LGTM, just tweak two names and it's good to merge.
