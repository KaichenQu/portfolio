# PTAL

**Full name**: Please Take A Look

Nudges a reviewer or directs someone specifically to look at your change.

![A pull request brings branch changes to code review before they are merged into the mainline.](../Diagrams/pr.review-flow.svg)

Example usage:
> Done — @alice PTAL.
