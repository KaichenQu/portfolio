# VPS

**Full name**: Virtual Private Server
**Chinese**: 虚拟专用服务器

A rented virtual machine at a hosting provider (OVH, GoDaddy, Tencent Cloud, Baidu Cloud), often a few dollars a month. Cheap, disposable and anonymous enough that most SSH dictionary scanning on the public internet originates from them, either rented for the purpose or compromised. A geolocation lookup that returns `hosting: true` for an attacking IP means a datacentre box, not a person.

Usage example:
> All six IPs fail2ban is holding are VPS hosts in five countries; none is a home connection.
